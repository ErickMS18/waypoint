# inbox/

Drop job postings you found anywhere here (LinkedIn, a friend's message, a company site).
One posting per `.txt` or `.md` file. Optional first lines (front matter):

```
title: Machine Learning Engineer
company: Acme
url: https://example.com/job/123
location: Remote - Brazil
---
<paste the full posting text here>
```

`waypoint collect` ingests every file in this folder. Everything here except this README is git-ignored.
